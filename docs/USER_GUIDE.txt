PinkPDF 1.0.0 사용 설명서
=========================

인터넷 연결 없이 내 PC 안에서 PDF를 합치고, 나누고, 압축하고, 변환하는 무료 프로그램입니다.
파일은 어디로도 전송되지 않습니다.


■ 설치하기 (권장)

1. PinkPDF-Setup.exe 를 실행하고 [설치]를 누릅니다. 관리자 권한은 필요 없습니다.
   - 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누르세요.
     (전자 서명이 없는 새 프로그램이라 나오는 안내입니다.)
   - 설치 위치를 바꾸려면 [위치 변경]을 누르세요.
2. 시작 메뉴나 바탕화면의 'PinkPDF'로 실행합니다.
3. 파일을 오른쪽 클릭하고 [보내기] → [PinkPDF]를 고르면 그 파일을 넣은 채로 열립니다.
   (Windows 11에서는 [더 많은 옵션 표시] 안에 있습니다.)
   PDF 여러 개는 합치기, PDF 하나는 압축하기, 사진은 이미지를 PDF로, 문서는 문서를 PDF로 화면이 열립니다.

설치 없이 쓰려면 PinkPDF.exe 하나만 원하는 폴더에 두고 실행해도 됩니다.

■ 제거하기

Windows 설정 → 앱 → 설치된 앱 → 'PinkPDF' → [제거]
(만들어 둔 결과 파일은 지워지지 않습니다.)


■ 할 수 있는 일

합치기
  - 여러 PDF와 이미지를 원하는 순서로 하나의 PDF로 묶습니다. (카드를 끌어서 순서 변경)
  - 파일마다 필요한 쪽만 고를 수 있습니다. 예: 1-3, 5, 8-
  - 파일마다 책갈피를 만들어 줍니다.

나누기
  - 범위별로 나누기 (예: 1-3, 4-8, 9-), 몇 쪽씩 묶어서 나누기, 한 쪽씩 모두 나누기
  - 원하는 쪽만 뽑아 새 PDF 만들기 (쪽 미리보기를 눌러서 고를 수 있습니다)

압축하기
  - 가볍게(화질 그대로) / 권장(150dpi) / 강하게(100dpi) / 최대로(72dpi) / 직접 정하기
  - 사진을 흑백(회색조)으로 바꿔 더 작게 만들기
  - 글자와 도형은 그대로 두고 사진만 알맞은 해상도로 다시 저장합니다.
  - 결과가 원본보다 커지면 원본과 같은 파일을 저장합니다.

변환하기
  - 이미지를 PDF로: JPG, PNG, GIF, BMP, TIFF, WEBP
      JPG는 다시 압축하지 않아 화질이 그대로이고, 휴대폰 사진의 방향도 바로잡습니다.
  - PDF를 이미지로: PNG 또는 JPG, 96 / 150 / 300dpi
  - 문서를 PDF로: Word, Excel, PowerPoint, 한글(hwp, hwpx) 등
      PC에 설치된 Microsoft Office, 한컴오피스 한글 또는 LibreOffice(무료)를 사용합니다.
      한글 문서를 바꿀 때 한컴오피스가 접근 허용 여부를 물으면 [모두 허용]을 누르세요.
  - PDF를 Word로: Microsoft Word 2013 이상 또는 LibreOffice가 필요합니다.
  - PDF에서 글자 추출: 메모장에서 열리는 .txt 파일로 저장합니다.

암호가 걸린 PDF는 암호를 입력하면 처리할 수 있고, 결과 파일은 암호 없이 저장됩니다.


■ 결과 파일이 저장되는 곳

  - 기본: 원본 파일과 같은 폴더
    이름 뒤에 _합본, _압축, _나누기 등이 붙습니다. 원본 파일은 절대 덮어쓰지 않으며,
    같은 이름이 있으면 (2), (3)처럼 번호를 붙입니다.
  - 창으로 끌어다 놓은 파일: 문서 폴더 안의 'PinkPDF' 폴더
  - 왼쪽 아래 [설정]에서 항상 특정 폴더에 저장하도록 바꿀 수 있습니다.


■ 필요한 환경

  - Windows 10 또는 Windows 11 (64비트)
  - Microsoft Edge WebView2 런타임
    Windows 11과 업데이트된 Windows 10에는 이미 들어 있습니다.
    없으면 프로그램이 기본 웹 브라우저에서 열리고, 기능은 똑같이 동작합니다.


■ 문제가 생기면

  - 창이 열리지 않으면 명령 프롬프트에서  PinkPDF.exe -browser  로 실행해 보세요.
    (기본 웹 브라우저에서 열립니다.)
  - 백신 프로그램이 처음 보는 프로그램이라며 막을 수 있습니다. 이 경우 예외로 허용해 주세요.
  - 기록 파일:   %LOCALAPPDATA%\PinkPDF\app.log
  - 설정 파일:   %LOCALAPPDATA%\PinkPDF\settings.json
    (탐색기 주소창에 %LOCALAPPDATA%\PinkPDF 를 입력하면 폴더가 열립니다.)


■ 라이선스

이 프로그램은 무료입니다. 함께 쓰인 오픈소스(pdfcpu, PDF.js 등)의 라이선스는
THIRD_PARTY_LICENSES.txt 에 있습니다.
